你好，世界 👋

每个博客的第一篇都值得被认真对待，哪怕只是写给未来的自己看。

欢迎来到我的小站。这是第一篇文章，我想用它来做个自我介绍，顺便记录一下最近的日常和想法。如果你恰好读到，那就当是一次隔空的闲聊吧。

为什么突然开博客？

  • 想有个地方沉淀自己的思考和经历
  • 为了倒逼自己持续输入和输出
  • 觉得有个个人网站很酷

总之，今天终于迈出了第一步。

近况 · 生活的三个切片

📦 工作 / 学业 / 项目

正在做的事：和大伙一样，上班、陪家人，在B站学习电磁学和计算机网络；
遇到的挑战：上班嘛，有不少考试和比赛，可能抽签抽到我，随心而安；
一点小成就：花了两个晚上，把这个网站发布到了GitHub上。

🌱 生活 / 兴趣 / 日常

  • 阅读：最近在看《穷查理宝典》，读到[第1章]，[时事造英雄]。
  • 英超：Glory，Glory，MU！！！
  • 新尝试：改善自己的体态，让自己变得更好。

一个细节：好久没有看读书app了，好多书在吃灰。后面让我来拯救它们。

💭 精神 / 思考 / 感悟

最近常想的一个问题是：好久不运动了，是不是要动起来？

下一步的小计划

  • 这个博客有些功能还不会使用，有时间摸索摸索；
  • 每周至少更新一篇，哪怕只是几百字；
  • 读完手头那本《穷查理宝典》并写读后感；
  • 学完《MIT 802》公开课，老师一步一步推导真的很牛X。

最后，写给你，也写给我自己

博客的第一篇文章总是有点“仪式感”，但我知道更重要的是坚持下去。如果你看到了这里，非常感谢你的耐心——作为回报，我保证下一篇会更有内容 😄

如果有任何想聊的，欢迎在评论区留言（或者通过 Github 找到我）。
